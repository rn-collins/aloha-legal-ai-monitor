# Legal AI Guidance Monitor

A source-tiered register of verified legal AI ethics authorities and official-source candidates. Built by RN Collins, JD Candidate.

**Live:** https://aloha-legal-ai-monitor.vercel.app

## Repository contents

`api`, `favicon.svg`, `package-lock.json`, `package.json`, `robots.txt`, `sitemap.xml`, `vercel.json`

## Local development

```sh
npm ci
npm test
npm run build
```

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
